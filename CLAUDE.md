# My First Agent Project

## What this project does
A learning project to practice Claude Code and build my first agent.

## Rules
- Always ask before deleting any files
- Explain what you're doing before doing it
- Keep code simple and beginner-friendly

## Stack
- Python (preferred language)
- No external dependencies unless necessary


## Learning Goal
Master Claude Code in 4 weeks. Build a content creation 
agent team (creative director, graphic designer, ad manager, 
video creator).

## Coaching style
Be direct and honest. Explain what you're doing before doing 
it. Don't over-engineer. Call out when I'm going off track.

## North star
Every session should build toward the content agent team goal.
